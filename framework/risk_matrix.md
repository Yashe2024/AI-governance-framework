# AI Risk Matrix

| Risk | Example | Control |
|---|---|---|
| Data | Sensitive information | Classification, access controls |
| Model | Hallucination | Evaluation, grounding |
| Security | Prompt injection | Input validation, tool restrictions |
| Bias | Unequal outcomes | Segment evaluation |
| Operations | Model degradation | Monitoring |
| Cost | Runaway usage | Budgets, rate limits |
| Governance | Untraceable decision | Audit logs |
| Human factors | Over-reliance | Human review thresholds |
