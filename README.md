# Enterprise AI Governance Framework

A practical operating framework for governing enterprise AI systems from ideation through production.

## Governance Lifecycle

```mermaid
flowchart LR
A[Use Case Intake] --> B[Risk Classification]
B --> C[Data Governance]
C --> D[Model Governance]
D --> E[Prompt / RAG Governance]
E --> F[Agent Governance]
F --> G[Evaluation]
G --> H[Runtime Monitoring]
H --> I[Human Oversight]
I --> J[Audit & Review]
```

## Core Artifacts
- AI use-case assessment
- Risk matrix
- Model evaluation record
- Prompt/RAG review
- Agent tool permission matrix
- Human oversight matrix
- Incident register
- AI vendor assessment
- Cost assessment

## Risk Tiers
**Tier 1 — Low:** informational assistance  
**Tier 2 — Moderate:** business recommendations  
**Tier 3 — High:** material customer/financial/operational impact  
**Tier 4 — Restricted:** regulated or prohibited use without formal controls

The tiers are a portfolio framework and should be adapted to the organization's legal and regulatory requirements.
